PII Guardrail

        
Protects sensitive values in input, tool results, final output, and memory where applicable. It is an application guardrail, not only a prompt instruction.

      

      

        
Sanitized Memory

        
Keeps safe previous context for follow-ups, such as "Show customers from Mumbai" followed by "Only show Gold tier", without storing raw sensitive data.

      

      

        
DAB MCP Access

        
Approved read-only tools mediate database access. The LLM requests tools but does not connect directly to SQL Server.

      

      

        
Structured Response

        
Returns status, message, columns, rows, warnings, and notes predictably for the UI. This format is helpful, but it is not the security layer.
