Interactive Query Flow

A concise architecture walkthrough for the POC: a natural-language customer question moves through the chat API, request-local PII protection, Spring AI orchestration, a secure MCP tool boundary, Microsoft Data API Builder, SQL Server, sanitized memory, and a policy-aware final UI response.

Example request

"give me the details of customer Ethan Thomas"

customer lookup protected AI path read-only data access

PII ProtectedSensitive values are tokenized before external model use.
Read OnlyThe model can request approved read tools, not direct database access.
Structured OutputResponses return predictable status, text, rows, warnings, and notes.
Sanitized MemoryConversation history stores protected content for safer follow-ups.
